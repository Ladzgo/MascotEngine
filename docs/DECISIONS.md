# Decisions log

Non-obvious choices, newest last.

1. **Remotion + Node/TS** (as briefed). No Python renderer needed so far.
2. **Line boil via SVG filter, not path jitter.** One `feTurbulence` + `feDisplacementMap` filter (`#boil`) whose `seed` changes every 3 frames (`src/fx/boil.tsx`). It wobbles every stroke (placeholder mascot, charts, boxes, text) uniformly, is deterministic (seed from frame number) and far less code than per-path jitter. Real PNG poses are not boiled (static art, as briefed).
3. **Audio is mixed outside Remotion.** Remotion renders silent video (`muted`), `src/pipeline/audio.ts` synthesises SFX in code, places narration files (`episodes/<id>/audio/scene-N.wav|mp3|m4a`, if present) and a music bed (first file in `assets/music/`, sidechain-ducked), then `ffmpeg loudnorm` to about -14 LUFS and mux. Reason: frame-exact control, no sample files needed for the MVP.
4. **Preview = 1280x720 via Remotion `scale: 2/3`**, final = 1920x1080. One layout, no second set of coordinates.
5. **Scene timing is owned by the director, not the TTS.** TTS gives per-scene speech duration and word times; the director adds a content-dependent tail (counting number, chart draw, list items not mentioned in narration) and writes `startSec/durSec` into `decisions.json`. Real audio is placed at `startSec + speechStart`.
6. **Transitions overlap the previous scene's tail.** Scene i starts its transition 12 frames before `startSec`; the previous scene is frozen on its last displayed frame (`prevLast`) underneath, so the "previous scene's last frame" requirement holds and total length is unchanged. Each transition layer carries its own paper background (otherwise layers are transparent and the old scene shows through).
7. **Director scoring**: `content_fit x seeded_noise x prev-scene penalty x history-frequency penalty`. Layout and camera are chosen jointly so the trigram penalty (type|layout|camera across 3 scenes, vs the last 5 episodes) sees the combination. Seed = hash(`id:seed`).
8. **Accent colours live in `src/accents.ts`**, not in the director, so the browser bundle never imports `node:fs`.
9. **Fonts**: Archivo Black (display) and Poppins 500/700 (sans), SIL OFL, copied from `@fontsource` into `assets/fonts/`.
10. **Numbers on screen come only from episode.json.** The count-up in `big_number` ends on exactly `scene.value`; chart axis ticks are derived from the data range (nice max), labels from the file.
11. **Silent TTS** estimates 2.6 words/sec with length/punctuation weighting; ElevenLabs and local-recording adapters are stubs until milestone 6.
12. **ep002 numbers fixed**: $500/month at 7% (monthly compounding) = $86,542 / $260,463 / $609,985 after 10/20/30 years (initial draft used annual contributions and gave 566,764). Contributed $180,000, growth $429,985.
