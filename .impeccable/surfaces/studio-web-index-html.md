# Surface: Mascot Engine Studio (studio/web)

Mode: Operate. Solo creator, one episode at a time, desktop. UI English. Generate runs the whole chain automatically.

## Direction contract

THESIS: The studio is an ink-on-paper production desk. The one idea: the episode's own accent colour and a hand-boiled ink line run through the shell, so the tool already looks like the channel it makes. Refuses the dark-dashboard-with-neon default.
OWN-WORLD: Paper #f6f1e4 ground, ink #1b1b1f rail and strokes, panels one step lighter paper with 2px wobbling ink borders, Archivo Black for titles and numbers, Poppins for everything else. Accent = current episode's accent from decisions.json. State colours: green done, tomato error, accent running.
STORY: Pick an episode, press Generate, watch the stage track fill, play the preview, tweak any scene in the inspector, regenerate only what changed, then the final and Shorts are ready to download.
FIRST VIEWPORT: Ink left rail (episodes, New). Top bar with title and one large accent Generate button. Centre: 16:9 player over the storyboard strip, scene cards sized by duration. Right inspector for the selected scene. Bottom stage track (voice, direct, preview, final, shorts) with live status.
FORM: Storyboard editor, position 5 of the grounded list, seed:784d9c568025f253. Signature move: line-boil on borders and the progress stroke draws itself in ink while a stage runs.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
