# Mascot concepts (faceless EN finance channel, dry/cynical)

Each SVG is built from id'd groups (legs, arm-left/right, body, accent, face > eyes/brows/mouth/extras). Recolour via `--accent` on `.accent` shapes.

- **Penny** - a coin in a tie, deadpan accountant energy; the round silhouette reads at 100px and "money that has seen things" is the channel's joke.
- **Bean** - a bean in a beanie (accent: band), blank-faced everyman; huge empty face gives the dry expressions maximum room.
- **Moth** - the moth that flew out of your wallet, wrapped in a scarf (accent); smug know-it-all with the widest silhouette and most distinctive shape.

Files: `concept-<name>.svg/.png` (sheet), `concept-<name>-full.svg` (1200x1500), `compare.png`.
